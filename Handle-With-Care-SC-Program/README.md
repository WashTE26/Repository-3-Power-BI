# Handle With Care – South Carolina Program

## Project Overview

This project demonstrates my use of Microsoft Power BI to support reporting and data visualization for the Handle With Care – South Carolina Program.

The purpose of the reporting was to organize program information, identify trends, and present data in a clear visual format for review by program leadership and stakeholders.
